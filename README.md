# E-Commerce Sales Analysis (Olist Dataset)

## Project Overview
This project focuses on analyzing an e-commerce dataset (Olist) using SQL and Tableau to uncover key business insights.  
The goal is to understand revenue trends, customer behavior, and sales performance across categories and regions.

## Objectives
- Analyze overall revenue and order trends  
- Identify top-performing product categories  
- Understand regional sales distribution  
- Track key KPIs like Total Revenue, Orders, and AOV  
- Generate actionable business insights  
 
## 🛠 Tools Used
- SQL (MySQL)
- Tableau Public
- Excel / CSV Dataset


## Key KPIs
- **Total Revenue:** 15.8M  
- **Total Orders:** 95,420  
- **Average Order Value (AOV):** 161
  
## 📌 Project Highlights
- Built an end-to-end data analysis project from raw dataset to dashboard  
- Wrote 30+ SQL queries for data extraction and KPI analysis  
- Designed an interactive Tableau dashboard for business insights  
- Derived actionable insights to support business decision-making

## Key Insights
1. Revenue peaks during mid-year, followed by a noticeable decline in later months  
2. A small number of product categories drive the majority of total revenue  
3. Sales are highly concentrated in a few key states, indicating regional dependency  
4. Customer retention is low, suggesting most users are one-time buyers
   
## Business Impact
This analysis helps stakeholders:
- Identify high-performing product categories to increase revenue
- Focus on top states contributing maximum sales
- Understand seasonal trends for better inventory planning
- Improve marketing strategies based on customer purchase patterns
