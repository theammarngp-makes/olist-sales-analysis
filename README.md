# E-Commerce Sales Analysis (Olist Dataset)

## Project Overview
This project focuses on analyzing an e-commerce dataset (Olist) using SQL and Tableau to uncover key business insights.  
The goal is to understand revenue trends, customer behavior, and sales performance across categories and regions.

## Objectives
- Analyze overall revenue and order trends  
- Identify top-performing product categories  
- Understand regional sales distribution  
- Track key KPIs like Total Revenue, Orders, and AOV  
- Generate actionable business insights  

## Tools 
- SQL (MySQL)
- Tableau Public
- Excel / CSV Dataset


## Key KPIs
- **Total Revenue:** 15.8M  
- **Total Orders:** 95,420  
- **Average Order Value (AOV):** 161

## 🔍 Key Insights
1. Revenue shows strong growth during mid-year with a drop in later months  
2. Top categories contribute a major share of total revenue  
3. Sales are concentrated in a few key states  
4. Business performance heavily depends on a few high-performing segments  


## Business Recommendations
- Focus marketing on top-performing categories  
- Improve retention strategies for consistent revenue  
- Expand in high-performing regions  
- Optimize low-performing categories  

## How to Use
1. Download dataset from `dataset/` folder  
2. Run SQL queries from `sql_queries/`  
3. Open Tableau dashboard to explore insights
