# Project Scope

## In Scope

- Revenue, order volume, and AOV analysis at the overall, category, regional, and monthly level
- Data cleaning and feature engineering on the Olist public dataset (2016–2018)
- SQL-based KPI extraction organized by business module
- Interactive Tableau dashboard for self-serve stakeholder access
- Business insight synthesis and horizon-based recommendations (short/medium/long-term)

## Out of Scope (this phase)

- Predictive forecasting or machine learning models (see `docs/future_improvements` note in README — flagged as a future phase, not attempted here)
- Customer-level lifetime value modeling beyond a simple, clearly-labeled proxy
- Live/real-time data integration — this analysis uses a static, historical dataset export
- External benchmarking against population or competitor data (flagged in `06_Business_Questions.md` as an open question requiring data not present in this dataset)

## Why scope is stated explicitly

Stating what was **not** attempted is as important as stating what was. It prevents a reader from assuming this analysis claims more than it delivers, and it gives a clear, honest on-ramp to the "Future Improvements" work without overselling the current deliverable.
